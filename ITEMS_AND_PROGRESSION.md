# Items, Materials & Progression System

**Total Gameplay Duration:** 1-3 months (Main Campaign 0-100%)  
**Early Game Phase:** First 24 hours (Basics tutorial, first missions, crafting introduction)

---

## Progression Timeline (0-100%)

### Phase 1: Basics & Tutorial (0-10%) - First 24 Hours
- **Duration:** 10 minutes - 24 hours
- **Location:** Space Station Hub + Safe Zone
- **Key Activities:** Character creation, spaceship selection, basic crafting, first 3-5 missions
- **Unlock:** Basic tools, Tier 1 materials, simple upgrades

### Phase 2: Frontier Expansion (10-30%) - Days 2-7
- **Duration:** 2-7 days
- **Location:** Inner asteroid fields, safe moons
- **Key Activities:** Mining, basic combat, crafting progression
- **Unlock:** Tier 2 tools, medium-range upgrades, first multi-stage missions

### Phase 3: Resource Mastery (30-50%) - Week 2-3
- **Duration:** 1-2 weeks
- **Location:** Mid-zone asteroids, dangerous moons
- **Key Activities:** Advanced crafting chains, combat encounters, base building intro
- **Unlock:** Tier 3 tools, advanced weaponry, base construction

### Phase 4: Deep Space Exploration (50-70%) - Week 3-4
- **Duration:** 1-2 weeks
- **Location:** Deep space sectors, rare asteroid fields
- **Key Activities:** Boss missions, faction wars, base expansion
- **Unlock:** Tier 4 tools, specialized equipment, faction-locked items

### Phase 5: Endgame & Mastery (70-100%) - Week 4+
- **Duration:** 2-4 weeks
- **Location:** Void zones, legendary sectors, player-controlled space
- **Key Activities:** Elite raids, PvP warfare, optimization
- **Unlock:** Mythic items, experimental tech, cosmetics

## Crafting Material Chains

### Chain 1: Basic Alloys
```
Copper Ore → (Furnace, 30s) → Copper Plate (x2)
Iron Ore → (Furnace, 30s) → Iron Plate (x2)
Copper Plate (3) + Tin Ore (2) → (Furnace, 45s) → Brass Ingot
Copper Plate (4) + Tin Ore (1) → (Furnace, 45s) → Bronze Ingot
Iron Plate (5) + Scrap (4) → (Furnace, 2m) → Steel Ingot (x3)
```

### Chain 2: Wiring Progression
```
Thin Wires (4) → (Crafting, 15s) → Thick Wires (1)
Thick Wires (3) → (Crafting, 45s) → Ribbon Wires (1)
Ribbon Wires (3) + Copper Plate (2) → (Crafting, 1m) → Quantum Wire (1) [rare]
```

### Chain 3: Electronics
```
Thin Wires (3) + Copper Plate (1) + Solder → (Soldering Iron, 30s) → Computer Chip
Computer Chip + Thin Wires (2) → (Crafting, 1m) → RAM Module
Computer Chip (2) + Advanced Chip Materials → (Crafting, 2m) → Advanced Chip [rare]
```

### Chain 4: Power Systems
```
Steel Ingot (2) + Copper Plate (2) + Capacitor → (Crafting, 1m) → Battery Cell (Standard)
Battery Cell (Standard, 3) + Fusion Material → (Crafting, 3m) → Battery Cell (Advanced)
Battery Cell (Advanced) + Rare Power Crystal → (Crafting, 5m) → Fusion Cell [rare]
Fusion Cell + Celestite → (Crafting, 10m) → Infinite Core [legendary]
```

### Chain 5: Weapon Progression
```
Thick Wires (3) + Copper Plate (2) + Steel Ingot → (Crafting, 2m) → Laser Module
Laser Module (2) + Computer Chip + Advanced Materials → (Crafting, 3m) → Laser Turret
Laser Turret + Ribbon Wires (4) + Rare Power Crystal → (Crafting, 5m) → Plasma Cannon Module [rare]
Plasma Cannon Module + Void Shard → (Crafting, 8m) → Singularity Projector [epic]
```

## Progression Checklist (0-100%)

### 0-10% Completion (First 24 Hours)
- [ ] Complete tutorial missions (space station basics)
- [ ] Unlock first 3 crafting recipes
- [ ] Obtain Tier 1 materials (100+ scrap, 30+ ore)
- [ ] Complete first mission choice (Safe or Dangerous Moon)
- [ ] Craft first tool (Small Drill or Wrench Set)
- [ ] Reach Character Level 5

### 10-30% Completion (Days 2-7)
- [ ] Complete 15-20 missions
- [ ] Unlock Tier 2 crafting chain (Steel, Brass, Bronze)
- [ ] Craft first medium tool (Medium Drill, Laser Cutter)
- [ ] Accumulate 500+ coins
- [ ] First major ship upgrade
- [ ] Build basic base on home moon
- [ ] Reach Character Level 15

### 30-50% Completion (Week 2-3)
- [ ] Unlock advanced crafting (Quantum Wire, GPU Module)
- [ ] Complete 10 dangerous zone missions
- [ ] Obtain first Rare Power Crystal
- [ ] Craft first Tier 3 weapon
- [ ] Accumulate 5000+ coins
- [ ] Expand base with multiple modules
- [ ] Join faction or player corporation
- [ ] Reach Character Level 30

### 50-70% Completion (Week 3-4)
- [ ] Access deep space zones
- [ ] Defeat first epic-tier boss
- [ ] Obtain Mithril/Cobalt materials
- [ ] Craft Quantum Drill or Dimensional Saw
- [ ] Build advanced defensive structures
- [ ] Accumulate 50000+ coins
- [ ] Establish trade routes
- [ ] Reach Character Level 50

### 70-100% Completion (Week 4+)
- [ ] Access void zones
- [ ] Defeat multiple legendary bosses
- [ ] Collect all Tier 4 materials
- [ ] Craft legendary weapons
- [ ] Build ultimate base/capital ship
- [ ] Accumulate 500000+ coins
- [ ] Dominate faction warfare
- [ ] Reach Character Level 100+
